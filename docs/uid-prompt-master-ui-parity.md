# External Prompt Master visual parity

The external Render page restores the compact visual language from the historical ChatGPT Prompt Master source retained in `uid-brands-workflow.ts`: 600px shell, original light/dark tokens, mint selected pills, toolbar/collapse, Task/Feedback tabs, grouped feedback cards and bottom copy dock. It does not serve the old embedded runtime.

The page remains a generic local-only composer. No task/image hydration, host bridge, storage, upload, login, automatic send, queue or Train is added. Canonical production slots, per-block scope, exclusions, ten-block limit, explicit overall scope, manual-copy fallback and chat-side task/version/inventory checks remain. A Task tab prepares a Onepage brief; actual route/research/QC verification occurs in chat, not on this static page.

The primary panel URL is the existing Render host at `/onepage-panel.html`. Relevant Onepage outcomes provide this link with short stage-aware instructions: open the appropriate tab, choose targets/groups where applicable, copy, and paste/send into the same conversation. Direct chat feedback remains available. Content guidance does not suggest selecting images that have not been generated. The page is optional and never embedded or automatically opened.

Existing cached ChatGPT HTML and real host thread behavior remain outside this page's control. Desktop public browser checks and automated behavioral checks are distinct from mobile/device validation; deployment notes report each honestly.
