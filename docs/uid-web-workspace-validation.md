## Independent adversarial review

Confirmed and fixed before release:

1. Occasion section feedback had incorrectly inherited a mobile alias by asset name. The manifest now derives every leaf's section from actual pinned canonical DIV ancestry. GTK and FAQ regressions verify that Product Details never leaks into Occasion scope.
2. Review or package output could replace the accepted render. An immutable approved-artwork digest now binds exact snapshot, content, manifest, template, canonical identity and cached preview bytes before submission and commit. Changed renders, omitted/swapped slots, restarts and races are rejected. The original exploit was independently replayed and produced zero ZIPs.
3. Express case-insensitive routes could fall through case-sensitive middleware checks to the legacy 14 MiB parser/public preflight. The new outer gateway wrapper now mounts terminating private routes before the unchanged legacy app. Lowercase, uppercase, mixed-case and unknown workspace requests all keep the workspace parser and same-origin boundary; unrelated legacy routes keep their original behavior.
4. A responsive SOURCE highlight was cleared by the later IMG pass. The runtime now paints the actual rendered IMG once using its active responsive source, and updates on resize. VM DOM-contract tests verify mobile selection/highlight and desktop transition. This is not a browser pixel comparison.
5. A shared reverse-proxy socket could exhaust password-login limits for every member. Production login now requires an explicit reviewed client-resolution and durable account/client-throttling adapter; deployment must not infer client identity from arbitrary forwarded headers. Independent replay confirmed production without protection returns 503 with zero provider calls, 20 legitimate same-ingress successes do not consume failure limits, spoofed forwarded headers do not become client identity, and limiter failures never issue a cookie. The real reviewed durable limiter remains unconfigured.

6. Upload-status GET could reconcile and delete orphan objects without mutation-origin checks. GET is now read-only; reconciliation uses protected POST. Cross-origin/missing-origin cookie and foreign-origin bearer regressions deny all side effects.
7. Unknown budget reservation/intent commits could be classified as ordinary failed-before-submit outcomes. Accounting uncertainty now takes precedence and keeps task/run unknown, preserving recovery and preventing resubmission.
8. Cancellation, lease expiry or membership revocation during artifact staging could allow a late PUT. Exact output identity is journaled first, and actual object PUT and OpenAI fetch boundaries recheck the durable run/fence/current authorization after staging.
9. Source-image decoding relied on ambient Sharp and failed in CommonJS bundles. It now resolves the declared isolated decoder runtime and has real decode/CJS regressions.

Research now reuses the exact retained originals and rejects conflicting same-URL bytes. Effective opacity, ancestor hidden state and clipping are checked conservatively.
